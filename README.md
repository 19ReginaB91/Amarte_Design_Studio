# Amarte Design Studio

A creative multi-page website for a handmade art and personalized gift studio.

## Live Demo

[Open Website](https://19ReginaB91.github.io/Amarte_Design_Studio/)

## About the Project

Amarte Design Studio is a frontend project focused on emotional branding, handmade art, personalized gifts and creative presentation.

The website includes several pages, a hero image slider, gallery filtering, image modal, promo section and responsive navigation.

## Features

- Multi-page website
- Responsive layout
- Hero background slider
- Gallery with filters
- Image modal / lightbox
- Promo section
- Burger menu
- German content
- Prepared structure for future multilingual support
