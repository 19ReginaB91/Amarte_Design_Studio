# Creative Art Studio Website Concept

Responsive multi-page website concept for a creative art studio and personalized
gift brand.

Live project: https://19reginab91.github.io/Amarte_Design_Studio/

## Overview

This project is a portfolio website concept created to explore emotional visual
direction, handmade art presentation and a soft service-based user journey.

The concept is not an active client website. It was built as part of my frontend
and UI design portfolio to show how a creative brand can present services,
gallery content, promotional offers and contact options in a clear responsive
website.

## Concept

The design direction focuses on warmth, personal gifts, handcrafted work and
emotional storytelling. The website uses German-language content and a multi-page
structure to create the feeling of a small creative studio with a clear service
offer.
